# Full teaching human-readability audit — 2026-09-06

Scope: every teaching sequence in all six active phases. This audit is content/visual QA only. It does not change lesson order, exercise generation, adaptive learning, READY/RETAINED, review scheduling, checkpoint logic, or progression logic.

## Audit method

For each lesson I read the complete teaching sequence in order, then checked:

- what terminology and rules were already available to the learner;
- whether a screen depended on a later lesson;
- whether the body added information beyond the heading;
- whether adjacent screens repeated the same fact without a teaching reason;
- whether examples matched the rule being explained;
- whether note spelling matched the written theory rather than only the piano pitch;
- whether piano highlights and display labels matched the example;
- whether learner-facing copy exposed internal engine terminology;
- whether wording was more complicated than necessary for a beginner.

Theory statements were cross-checked against Open Music Theory material on intervals/inversion, major scales and scale degrees, minor-scale forms and relative keys, Roman numerals/chord quality, and the Circle of Fifths.

## Phase 1 — Intervals

1. **Perfect Unison & Perfect Octave** — Removed heading/body restatement. Opening now defines interval, size, and quality without dumping the future quality taxonomy. P1 explains same pitch, one spanned note name, and one physical key. P8 explains the next C, eight-note span, and two physical keys. Piano highlights remain C4 for P1 and C4+C5 for P8.
2. **Perfect 5th** — Keeps interval number tied to five written note letters, not semitone count. Defines `accidental` before the first sharp/flat spelling example. Keeps full Major/Minor/Augmented/Diminished theory out of the lesson.
3. **Perfect 4th** — Reworked the opening so the body explains the four-letter span instead of repeating the title. Inversion screens now progress definition → number partner → quality rule → practical connection.
4. **Major & Minor 3rds** — This remains the first point where Major/Minor exact quality is explicitly taught. Number still comes from written letters; half steps distinguish M3 vs m3. Enharmonic example keeps E♭ vs D♯ conceptually distinct.
5. **Major & Minor 6ths** — Reduced repetitive inversion wording and made each screen do a distinct job: rule, M3↔m6 worked pair, m3↔M6 worked pair, then retrieval strategy.
6. **Major & Minor 2nds** — Clarified half-step/whole-step keyboard distance and preserved written-letter logic. Removed any need to know diminished 3rds or double flats before the tritone lesson.
7. **Major & Minor 7ths** — Keeps 2↔7 inversion as the known bridge and avoids re-teaching the full inversion system on every screen.
8. **Tritone: A4 & d5** — Augmented/Diminished are formally defined here, not earlier. C→F♯ and C→G♭ remain the same piano distance but different written intervals. Double accidentals are defined before use.
9. **Interval Inversion Capstone** — Keeps the complete inversion rules together after their component pairs have been encountered. Number rule is stated as simple intervals adding to 9; quality rules remain separate.
10. **Cumulative Interval Drill** — Keeps all 14 written simple interval types explicit, preserves A4 vs d5 spelling, and removes learner-facing READY-style engine language from the teaching copy.

## Phase 2 — Major Scales

1. **Major Scale Formula** — Tonic is defined without prematurely teaching numbered scale degrees. Whole/half-step language connects to the interval knowledge already learned. Formula copy distinguishes reconstruction from eventual recall.
2. **Scale Degrees & Names** — Each paired-name screen now adds positional/interval meaning instead of merely repeating its heading. Final screen emphasizes the useful translation: name → number → note in the current key.
3. **Build Major Scales From Every Root** — Corrected the pitch-class definition so enharmonic names can belong to the same pitch class. The 12-root overview piano uses deliberate single spellings matching its written root list rather than generic sharp/flat slash labels.
4. **Major Scale Instant Recall** — Removed internal mastery-engine language. Screens now explain why distributed mixed recall is useful and why the drill rotates roots/task types.

## Phase 3 — Minor Scales

1. **Natural Minor Formula** — Keeps natural minor as the base collection and avoids previewing later harmonic/chord rules.
2. **Natural Minor From Every Root** — Keeps formula application distinct from the previous lesson and gives the all-roots piano context-correct labels.
3. **Harmonic Minor** — Explains the single raised-7 change, leading-tone effect, and resulting 6→7 gap without using Phase 4 chord construction as the explanation.
4. **Melodic Minor** — Explicitly identifies the classical ascending/descending form taught by this curriculum and avoids implying every real-world minor melody must follow it.
5. **Minor Scale Instant Recall** — Mixes roots/forms without leaking future chord vocabulary into the payoff screen.

## Phase 4 — Diatonic Chords

1. **Stacking 3rds** — Removed unexplained `tertian harmony` from the opening. Sequence is now method first (take every other scale note), then chord/triad/root/3rd/5th/diatonic vocabulary, then interval-based chord quality.
2. **Major Key Triads** — Roman numerals are disclosed progressively: first the numeral as the chord-root scale degree, then uppercase/lowercase/° as quality information. This removes duplicated explanation across two adjacent screens.
3. **Natural Minor Triads** — Verified the i–ii°–III–iv–v–VI–VII pattern and examples against the natural-minor collection.
4. **Harmonic Minor Triads** — Verified raised 7 correctly changes V, III, and vii° relationships. The V example follows from material already taught in Phase 3 and current chord-building method.
5. **Melodic Minor Triads** — Keeps this lower-priority pattern derivational and explicitly uses the ascending form taught in Phase 3.
6. **Diatonic 7th Chords** — Verified major, natural-minor, harmonic-minor, and ascending-melodic-minor seventh patterns. Dominant-seventh `quality` is kept distinct from dominant `function`, which is introduced later.
7. **Chord-Type Reference Table** — Preserves it as a lookup screen, defines d7 where needed, and removes internal READY/evidence language from the learner-facing payoff.
8. **Chord Function** — Explicitly separates chord quality from chord function and distinguishes the role words tonic/predominant/dominant from the earlier scale-degree names.
9. **Common Progression Vocabulary** — Verified the Roman-numeral examples transpose correctly and kept the progressions framed as useful vocabulary rather than exhaustive rules.
10. **Analyze Your Own Progressions** — Clarified the required input/context and keeps outside-scale chords labeled honestly without importing later chromatic-harmony explanations.

## Phase 5 — Relative Keys

1. **Relative Major / Minor** — Defines key signature at first need. The two piano screens now have separate jobs: establish the C-major physical key set, then show the same physical keys with A as tonic. `Cadence` jargon was removed from the tonic explanation.
2. **Same Chords, Different Numbers** — Verified the shared natural-minor/major triad collection and Roman-numeral rotation. Harmonic/minor exceptions stay explicitly separated.
3. **Fast Identification** — Reuses the already-taught m3 distance while adding the genuinely new requirement: the relative-key spelling must share the key signature.
4. **Relative-Key Instant Recall** — Keeps both directions, written key families, and calculation backup without turning the screen into a second full lesson on relative-key definition.

## Phase 6 — Circle of Fifths

1. **What the Circle Represents** — Clarified the map as key-signature relationships; clockwise P5, counterclockwise P4/P5 relationship, six shared notes, sharp/flat direction, and enharmonic seam were checked for consistency.
2. **Closely Related vs Distant Keys** — Keeps the useful close-key family definition and removes premature pivot-chord/modulation instruction. Near/far remains a relationship description, not an emotional rule.
3. **Use the Circle to Target Unfamiliar Keys** — Verified the circle-distance examples and keeps the workflow tied to already-learned scale, Roman-numeral, and relative-key skills.
4. **Practical Far-Side Transposition Drill** — Corrected/clarified the C-centered 4/5/6-step examples, preserves target-key spelling, and ends with an actual play/program task rather than another abstract circle fact.

## Piano-label audit

- The keyboard remains one connected C4→C5 octave with correctly placed black keys.
- Default black-key labels are now compact single spellings: C♯, D♯, F♯, G♯, A♯.
- Lessons that require flat spellings override those defaults contextually (for example A♭, E♭, B♭, G♭).
- No generic `C#/Db`-style slash labels remain on narrow piano keys.
- CSS clips/contains labels inside each black key so text cannot spill into a neighboring key on phone widths.
- P1 still highlights one C key; P8 still highlights both lower and upper C; A4/d5 use the same physical key with different written display labels.

## Final learner-eye pass

After the targeted edits, the sequences were read again in curriculum order. The final pass specifically removed or guarded against:

- `Its name is ...` restatements beneath headings that already provide the name;
- premature Major/Minor/Augmented/Diminished terminology;
- unexplained `accidental`, `pitch class`, `triad`, `diatonic`, Roman-numeral, and key-signature language;
- internal READY/RETAINED/evidence language in teaching copy;
- Phase 3 explanations that depend on Phase 4 chord theory;
- duplicate Roman-numeral explanations on adjacent Phase 4 screens;
- generic sharp/flat piano labels and label overflow;
- incorrect far-side Circle-of-Fifths distance wording.

Automated regression tests accompany this pass so these specific mistakes do not quietly return later.
